Exercise history · aligned rows

A’s one line per session, with B’s “set 1 under set 1”, and nothing reserved for the session with the most sets.

  1. A row is only as long as that session’s sets: a short day ends early, a one-off extra set adds one chip.
  2. All chips of one exercise share one width, so set N sits under set N in every row.
  3. A skipped set keeps its place as a dashed blank, so the sets after it don’t shift left.
  4. Chips are sized for the exercise’s usual set count plus one spare. If those don’t fit beside the date, the date moves above them, and an extra set that still doesn’t fit wraps.
