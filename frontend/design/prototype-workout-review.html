Workout review

Three directions for the page a finished workout opens to. All three drop the old fixed header for the same chrome as the mesocycle page, move the muscle split to the top, and show every lift next to the last time you did it, the same comparison as the grey targets while logging.

Real sets · Big Boi · week 3 day 1 (shown as “Pull”) vs week 2
A · GHOST SETS CHOSEN
Each set as a tile with last time’s set ghosted under it, what went up in blue, and a trend line of the last few best sets.
B · LEDGER
Numbers first: this week, last week and the change, set by set, in full-width columns. The densest option and the fastest to scan.
C · TREND
Each lift with its best set plotted across the block, so you see where this session sits. Less about last week, more about the arc.

How you get here

  • Tap a done session on the mesocycle grid. Open and upcoming sessions still open the workout screen.
  • Back always returns to the mesocycle.

Editing (the pencil)

Opens this session on the workout screen with Done editing instead of Finish workout, then returns here. Worth knowing: changing a past session’s set count today also changes the set count of that lift in later sessions you haven’t started.

Not shown

Myo-rep sets keep their MR / MM colour tag on the tile. Session notes and exercise notes go under the lift they belong to. A skipped session opens the workout screen as it does now, because that’s where Undo skip lives.
